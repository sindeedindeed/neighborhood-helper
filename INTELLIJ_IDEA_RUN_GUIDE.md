# ✅ RUN BUTTON IN INTELLIJ IDEA - Complete Guide

## IntelliJ IDEA Run Button Location

In **IntelliJ IDEA**, the Run button is in a **different location** than Android Studio!

---

## 📍 WHERE IS THE RUN BUTTON IN INTELLIJ IDEA?

### Location 1: Top Toolbar
```
┌─────────────────────────────────────────────────┐
│ File  Edit  View  Navigate  Run  Tools  Help   │
│     ▶ ⏸ 🐛 🔧                                  │  ← Top right
└─────────────────────────────────────────────────┘
```

The **▶ Run** button is usually in the **top right corner** near the search icon.

### Location 2: Run Menu
- Click **Run** menu at the top
- Select **Run 'app'** (or whatever your app is called)
- Or use keyboard shortcut: **Shift + F10** (Windows) or **Control + R** (Mac)

### Location 3: Gutter (Left Side)
- Open `MainActivity.kt`
- Look at the **left margin** (line numbers area)
- You might see a small **▶ Play icon** next to the `fun onCreate()` method
- Click it to run

---

## 🚀 STEPS TO RUN IN INTELLIJ IDEA

### Step 1: Sync Gradle
- **File** → **Sync** (or just wait for auto-sync)
- Wait 2-3 minutes
- Look at bottom for: "Gradle sync finished"

### Step 2: Build Project
- **Build** → **Build Project**
- Wait 1-2 minutes
- Look at bottom for: "Build completed"

### Step 3: Open Run Configuration
- **Run** → **Edit Configurations...**
- Make sure **app** is selected
- Click **OK**

### Step 4: Run the App
Choose ONE of these methods:

**Method A: Run Menu**
- Click **Run** menu
- Click **Run 'app'**

**Method B: Toolbar Button**
- Look for green **▶ Run** button in top toolbar
- Click it

**Method C: Keyboard Shortcut**
- Press **Shift + F10** (Windows/Linux)
- Press **Control + R** (Mac)

**Method D: Gutter Icon**
- Open `MainActivity.kt`
- Look for **▶** icon in the left margin
- Click it

## 🎯 FASTEST WAY IN INTELLIJ IDEA

1. **File** → **Sync** (wait for completion)
2. **Build** → **Build Project** (wait for completion)
3. Press **Shift + F10** (or **Control + R** on Mac)
4. Select emulator or device
5. App runs! 🎉
